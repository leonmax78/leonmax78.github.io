# 四海同舟欄位與翻譯確認表

入口：`planning/item-fields.html`。這是規劃工具，不會以 localStorage 的草稿直接覆蓋正式站設定。

## 確認流程

1. ITEM 欄位頁勾選顯示／隱藏，修改希望採用的中文欄名。
2. 「值對照」列出 ITEM 目前實際出現的全部原值、各值出現筆數與範例。資料分頁，搜尋會查整個欄位的所有值，不僅目前一頁。
3. Flag、Class 與作用方式欄位可切換完整原值／拆分代碼。組合旗標不應只靠其中一個 token 推斷全部限制。
4. Attack 已依使用者確認：1 最慢、2 次慢、3 普通、4 次快、5 最快。未確認的代碼保持原值，中文確認欄可先留空。
5. 「全站共用譯名」列出原始欄位／計算鍵與同義別名；例如 MagicAttack、m_attack、術攻都指向術法攻擊。此頁沒有可見性勾選，避免將 ITEM 的隱藏決定擅自套到降神或怪物能力。
6. 匯出 JSON 或複製變更摘要後交回確認。套用時應修改共用字典與欄位顯示規則，再跑各入口測試，不將原始數值／ID／遊戲說明替換成翻譯。

## 目前已同步的範圍

- 道具與商店商品共用 `itemDetailBodyHTML`，不再依載入順序退回英文原始欄位。
- ITEM、合成能力、怪物／封獸能力、降神比較／試算／推薦、武魂能力使用 `SZO_DISPLAY.label`。
- 共用 `SZO_DISPLAY.value` 處理攻速及職等。數值、比例、其他旗標效果沒有在本次擅自解碼或更改。
- 裝備系列名稱、遊戲原文說明、任務名稱及原始資料鍵不是同義能力欄名，不做全域文字替換。
- 初始清單沿用一般道具頁目前的 28 個原始文字欄位加 Icon。合成模擬既有的能力範圍先保留，待使用者選擇後再決定共同可見性範圍。

## 維護

- 欄名與能力別名：`js/data/display-dictionary.js`。
- 道具類型／種族代碼既有對照：`js/data/type-maps.js`；清單使用同一份資料，不另複製譯名。
- 選擇清單及原值資料：執行 `python tools/build_field_checklist.py` 重建。
- 測試：`node tools/test_display_dictionary.cjs`。可用 `PLAYWRIGHT_PATH` 指定 Playwright 安裝位置。
- 匯出 schema：`schemaVersion=1`、`status=draft-not-applied`；包含完整欄位選擇、共用譯名及使用者修改的值對照。

目前全站共用表先納入已接入的能力詞彙與 ITEM 欄位；未確認代碼不代表已完成翻譯。後續確認的新詞必須加入相同字典，而不是散落在各頁另寫一份。
